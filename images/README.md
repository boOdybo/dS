# 📷 دليل صور العرض التقديمي — AttendX Presentation Images

ضع الصور في هذا المجلد بالأسماء المحددة أدناه وسيتم إضافتها تلقائياً للعرض.

## الصيغ المدعومة
`.png` `.jpg` `.jpeg` `.webp` `.svg`

## قائمة الصور المطلوبة

| اسم الملف | الوصف | الشريحة |
|---|---|---|
| `breadboard_prototype` | صورة النموذج الأولي على Breadboard | Hardware Final |
| `final_pcb` | صورة PCB النهائية | Hardware Final |
| `assembled_system` | صورة النظام مجمّع في الغلاف | Hardware Final |
| `wiring_diagram` | مخطط التوصيلات الكامل | Wiring Diagram |
| `esp32_s3_board` | صورة لوحة ESP32-S3 | ESP32 Intro |
| `r307_sensor` | صورة حساس البصمة R307 | R307 Specs |
| `dfplayer_module` | صورة وحدة DFPlayer Mini | DFPlayer |
| `lcd_4x20` | صورة شاشة LCD 4×20 | LCD Intro |
| `neopixel_led` | صورة NeoPixel LED | NeoPixel |
| `pcb_schematic` | مخطط الدائرة الإلكترونية | PCB Schematic |
| `pcb_layout` | تخطيط اللوحة في Altium | PCB Layout |
| `pcb_3d_render` | رندر ثلاثي الأبعاد للوحة | PCB 3D |
| `3d_enclosure` | صورة الهيكل الخارجي المطبوع | 3D Design |
| `3d_parts` | صورة الأجزاء المطبوعة | 3D Parts |
| `system_overview` | صورة نظرة عامة على النظام | Architecture |
| `soldering_result` | صورة نتيجة اللحام | Soldering |

## مثال
لإضافة صورة النموذج الأولي، ضع الملف بالاسم:
```
public/images/breadboard_prototype.png
```
وسيظهر تلقائياً في العرض!
